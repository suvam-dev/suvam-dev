# Suvam Ghosh | Portfolio

A modern, high-performance portfolio website built with React, Vite, and Tailwind CSS. The site features a sleek, "scientific" dark theme with cyan and deep blue accents, glassmorphism UI components, and integrated 3D environments.

## 🚀 Live Demo
**[View the Live Deployment on Vercel](https://portfolio-react-chvbx9jo9-suvam-devs-projects.vercel.app)**

---

## 💻 Tech Stack
- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics:** [Spline](https://spline.design/) (`@splinetool/react-spline`)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Contact Form:** [EmailJS](https://www.emailjs.com/)
- **Deployment:** [Vercel](https://vercel.com)

## ✨ Key Features
- **Immersive 3D Landing Page:** Utilizes `react-spline` with `Suspense` for lazy-loaded interactive 3D elements.
- **Scientific Dark Theme:** Custom-tailored dark mode (`#050510` global background) featuring glowing neon cyan elements, grid layouts, and advanced glassmorphism.
- **Dynamic Projects Section:** Interactive carousel rendering GitHub repositories and live links with high-fidelity card animations.
- **Infinite Skills Carousel:** Seamless, animated marquee highlighting my technological expertise.
- **Functional Contact Form:** Seamlessly integrated with EmailJS to securely deliver messages.

## ⚙️ Running Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/suvam1061/portfolio-react.jsx.git
   cd portfolio-react.jsx-1
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Environment Variables**
   Ensure you have configured EmailJS credentials in `src/section/ContactSection.jsx` to receive emails.
