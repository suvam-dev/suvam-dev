## ✨ Site Features

**🪐 Immersive 3D Landing**  
Built with `@splinetool/react-spline` wrapped in React `Suspense` — the 3D scene loads lazily without blocking the critical render path.

**🔬 Scientific Dark Theme**  
Global background `#050510`, glowing cyan UI elements, CSS grid overlays, and glassmorphism cards create a cohesive "deep-space lab" atmosphere.

**🎠 Dynamic Projects Carousel**  
Keyboard and pointer navigable carousel with animated card transitions, GitHub links, and live demo CTAs — all driven from a single data file.

**⚙️ Infinite Skills Marquee**  
A seamless, CSS-animated marquee renders my technical skills with zero JS overhead after mount.

**📬 Functional Contact Form**  
EmailJS integration handles form submission server-side — no backend required, messages land directly in my inbox.

## 🚀 Run Locally

```bash
# 1. Clone
git clone https://github.com/suvam1061/portfolio-react.jsx.git
cd portfolio-react.jsx-1

# 2. Install
npm install

# 3. Start dev server
npm run dev
```

**Environment setup** — configure your EmailJS credentials directly in:
```
src/section/ContactSection.jsx
```

| Variable | Where to get it |
|---|---|
| `serviceId` | [EmailJS Dashboard](https://dashboard.emailjs.com/) → Email Services |
| `templateId` | EmailJS Dashboard → Email Templates |
| `publicKey` | EmailJS Dashboard → Account → Public Key |

## 🛠️ Build & Deploy

```bash
npm run build      # Production build → dist/
npm run preview    # Preview production build locally
npm run lint       # ESLint check
```

Continuous deployment is configured via **Vercel** — every push to `main` triggers an automatic production deploy.
